# CineVault NG

Static starter website for CineVault NG.

## Files
- index.html — complete homepage
- styles.css — responsive design
- script.js — search, genre filtering and search modal

## Deploy
Upload these three files to the root of your GitHub repository, then import that repository into Vercel. Vercel can automatically deploy commits from a connected Git repository.

## Legal use
Populate the site only with content you own, license, have permission to distribute/link to, public-domain works, or legitimate official viewing links. The demo titles are placeholders.
